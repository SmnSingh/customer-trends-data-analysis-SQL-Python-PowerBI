# 📊 Customer Behavior Analysis

## 📌 Project Overview

**Customer Behavior Analysis** is an end-to-end data analytics project that analyzes customer shopping behavior to identify patterns, trends, and business insights.

The project follows a complete data analysis workflow:

**Dataset → Python → EDA & Data Cleaning → PostgreSQL → SQL Analysis → Power BI Dashboard**

The goal of this project is to understand customer purchasing behavior, subscription patterns, product categories, revenue, sales, shipping preferences, and customer demographics.

---

## 🎯 Project Objectives

- Analyze customer purchasing behavior
- Explore and clean the raw dataset
- Perform Exploratory Data Analysis (EDA)
- Store and analyze data using PostgreSQL
- Write SQL queries to answer business questions
- Identify trends across product categories and customer groups
- Analyze customer subscription behavior
- Build an interactive Power BI dashboard
- Present insights in a clear and business-friendly way
